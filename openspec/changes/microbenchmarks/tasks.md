# Tasks

Rules that bind every task below (see design.md, Delivery process): the research note precedes the spike and the spike precedes the suites; implementation tasks add failing tests first and record red-then-green; every install is prefixed with `sfw`; each task lands as atomic commits by its implementer; a validation-and-fix phase (build, clippy on all targets with warnings denied, fmt check, full tests, `openspec validate`, diff review against the spec) runs before the next task starts; every number recorded comes from a run that passed the quiet-host guard, with the load averages beside it. Group 1 first; 2.1 before 2.2 to 2.5, which touch disjoint crates and can run in parallel; 3 after 2; 4 last.

- [ ] 1.1 Write `docs/research/microbenchmarks.md`: what criterion, divan, tango, glassbench, iai-callgrind and CodSpeed's compatibility layers, bencher and `github-action-benchmark` do (statistics, baselines, output formats, allocation counting, dependency weight, CI support), how projects keep benchmark noise down on shared hosts and in CI (quiet checks, sample settings, paired runs, instruction counts) and what agent-browser and the baseline tools measure of themselves, with sources; verify the note is reviewed and linked from design.md (Context7 does not index tango; the note reads its repository and says so)
- [ ] 1.2 Spike S8 in `spikes/s8-bench-harness/`: the decode of a generated 500-node snapshot through the shipped `protocol` crate, and a variant of it made about 5% slower by a calibrated amount of extra work, under each candidate harness that builds here; ten runs each on a quiet host (1-minute load under 4, none of the guard's processes using CPU, checked before every run and logged) and ten under a synthetic load of four busy cores; record per harness the coefficient of variation of the reported median, how many paired runs told the variant apart in the right direction, the wall time per run, the dependency count and whether its output is machine-readable per benchmark; deliver `docs/spikes/s8-bench-harness.md` with Setup, Measurements and Verdict, and rewrite design D13 with the choice and its numbers, D15's default load bound and D16's default threshold (twice the quiet CV, floor 5%); add the spike to `spikes/README.md`'s table; verify `openspec validate microbenchmarks --strict` passes and D13 cites the report
