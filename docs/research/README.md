# Research notes

State-of-the-art notes that open each task group. Per design.md's Delivery process, no implementation task in a group starts before its note exists.

Each note names what already exists, what this project reuses, where this design differs, and the sources, and is linked from design.md once reviewed. Notes are named by topic, for example `android-agent.md`, `simulator.md` and `protocol.md` (tasks 2.1 to 2.3 of the archived change `mobile-automation-foundation`), `microbenchmarks.md` (task 1.1 of `microbenchmarks`), on harness libraries, noise control and continuous benchmarking, and `ios-device.md` (task 1.1 of `physical-ios`), on physical iPhones: the device services and their transports, the tools that drive devices, the `idevice` crate, the frame paths and signing.

`docs/overview.md` draws on these notes, the spike reports and the end-to-end reports to answer how mobile-agent differs from the tools the notes survey, where it is faster, and what it supports and leaves out.
